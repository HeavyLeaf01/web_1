Fundamentos do Desenvolvimento Web

1. HTML (HyperText Markup Language)

O HTML é a linguagem de marcação que define a estrutura e o esqueleto de uma página web. É Importante notar que o HTML utiliza elementos como html, body e div para organizar o conteúdo de forma hierárquica.

2. Tags e Elementos

As tags são as instruções que dizem ao navegador o que cada parte do conteúdo representa. É Importante compreender que a maioria das tags vem em pares, como p para abrir um parágrafo e /p para fechá-lo.

3. CSS (Cascading Style Sheets)

O CSS é a linguagem de estilos usada para descrever a apresentação de um documento escrito em HTML. É Importante saber que propriedades como color, font-size e margin permitem transformar um documento de texto simples em um site visualmente atraente.

4. Seletores CSS

Seletores são os padrões usados para selecionar os elementos HTML que você deseja estilizar. É Importante dominar o uso de seletores de tipo, como h1, seletores de classe .minha-classe ou seletores de ID #meu-id para aplicar estilos específicos.

5. Atributos HTML

Atributos fornecem informações adicionais sobre os elementos e são sempre especificados na tag de abertura. É Importante lembrar que atributos como href (em links a) ou src (em imagens img) são essenciais para a funcionalidade da página.

6. O Modelo de Caixa (Box Model)

No CSS, cada elemento é representado como uma caixa retangular que envolve o conteúdo. É Importante entender como o padding, border e border-width interagem entre si para controlar o espaçamento e o layout final do site.
