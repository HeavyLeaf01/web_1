Tecnologias Web

HTML (HyperText Markup Language)
É a linguagem de marcação padrão utilizada para estruturar o conteúdo de uma página na web.
Define elementos como cabeçalhos, parágrafos, links e imagens através de tags.
CSS (Cascading Style Sheets)
É uma linguagem de estilo usada para descrever a apresentação e o layout de documentos HTML.
Permite controlar cores, fontes, espaçamentos e a responsividade do site em diferentes dispositivos.
JavaScript
É uma linguagem de programação de alto nível que adiciona interatividade e dinamismo às páginas web.
Permite a criação de mapas interativos, animações complexas e atualizações de conteúdo em tempo real.
HTTP (Hypertext Transfer Protocol)
É o protocolo de comunicação básico que permite a transferência de dados entre o cliente (navegador) e o servidor.
Funciona através de um sistema de requisições e respostas para carregar recursos como arquivos HTML e imagens.
React
É uma biblioteca JavaScript de código aberto focada na criação de interfaces de usuário baseadas em componentes.
Facilita o desenvolvimento de aplicações web de página única (SPA) com alta performance e reutilização de código.
