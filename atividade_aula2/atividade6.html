Tecnologias Web

Variável
Um espaço na memória do computador reservado para armazenar dados que podem ser alterados durante a execução do programa.
Algoritmo
Uma sequência finita de passos lógicos e bem definidos que deve ser seguida para resolver um problema ou executar uma tarefa.
Função
Um bloco de código reutilizável que executa uma ação específica e pode ser chamado em diferentes partes de um programa.
Sintaxe
O conjunto de regras que define a combinação correta de símbolos e palavras-chave que formam instruções válidas numa linguagem de programação.
Compilador
Um programa que traduz o código escrito numa linguagem de programação de alto nível para linguagem de máquina, para que o processador o consiga executar.
Depuração (Debugging)
O processo de identificar, localizar e corrigir erros (bugs) dentro do código de um programa.
